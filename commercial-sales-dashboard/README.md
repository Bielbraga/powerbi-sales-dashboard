# 📊 Commercial Sales Dashboard — Power BI

Dashboard desenvolvido como parte dos estudos práticos em Power BI, com foco na análise de desempenho comercial e indicadores de vendas.

## 🎯 Objetivo

O projeto apresenta análises relacionadas ao desempenho de vendas, fabricantes, categorias, segmentos, pontos de venda e regiões.

## 🛠️ Ferramentas

- Power BI
- Power Query
- DAX
- Excel

## 📁 Estrutura

- `dashboard.pbix` — arquivo principal do Power BI.
- `datasets/Dados_Comerciais.xlsx` — conjunto de dados utilizado no projeto.
- `images/dashboard.pdf` — exportação do dashboard para visualização.

## 📌 Observação

Projeto desenvolvido para fins de aprendizado e construção de portfólio em Business Intelligence e análise de dados.
